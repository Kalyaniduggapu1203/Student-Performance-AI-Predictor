# Student Performance AI Predictor

## Project Overview
This project uses Machine Learning to predict students' final academic performance.

## Dataset
- Dataset: Student Performance Dataset
- Source: UCI Machine Learning Repository
- Number of students: 649
- Input features: 30
- Target: Final Grade (G3)

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Models
- Linear Regression
- Random Forest Regression

## Evaluation Metrics
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

## Key Insights
- Previous grades (G1 and G2) have a strong relationship with final performance.
- Attendance-related information such as absences is useful for prediction.
- Previous failures are generally associated with lower final grades.

## Business Use Case
The model can support early identification of students who may benefit from additional academic support.
